# Customer — Packages

- `/portal/packages` — owned packages, pending review, empty state
- `/portal/packages/[entitlementId]` — sessions remaining, held/used/restored, expiry, redemption history

Copy uses “sessions remaining,” never a cash balance.

Booking form (`08-booking-form.md`) shows “Use a package” only for entitlements eligible for that session. Waitlist records an intended package without holding a credit.
