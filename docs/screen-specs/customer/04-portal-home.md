# Customer Portal — Home / My Bookings

```text
NAV: Home | My bookings | Schedule | Packages | Profile | Achievements(TBD)

Welcome, [Name]

NEXT UP                         NEEDS ATTENTION
Confirmed booking card           Up to 3 compact, actionable booking previews
                                [View all bookings that need attention →]

The overview places the next confirmed booking beside attention items, so the
customer can distinguish what is settled from what needs action at a glance.
The attention preview never expands the overview indefinitely: it routes to the
Pending tab on the separate My bookings page for the full actionable list.
```

Use human-readable statuses, never raw enum names.
