# Admin Portal — Dashboard

```text
DASHBOARD
[Today's Classes] [Pending Payments] [Cancellations] [Reschedules] [Waitlisted]

NEEDS ATTENTION
Payment proof -> Review
Cancellation -> Review
Reschedule -> Review

TODAY'S SCHEDULE
Time | Class | Coach | Capacity | Status
```

Prioritize operational actions over analytics.

## Financial summary cards

The dashboard may include lightweight operational cards such as:

```text
Today's Sales
Pending Refunds
Today's Occupancy
Coach Cost Today
```

Keep the dashboard focused on action; detailed analysis belongs in Reports.

## Coach dashboard

The built-in Coach role sees a teaching-only dashboard, not the studio
operations dashboard. It contains only the sessions assigned to the signed-in
coach, today’s session count and occupancy for those sessions, and an **Open
roster** action for attendance. Payment, cancellation, reschedule, refund,
sales, and coach-cost widgets are not shown.
