# Admin Portal — Class Management

```text
CLASSES                              [Add Class]
Yoga       Active       [Edit]
Boxing     Active       [Edit]
Capoeira   Active       [Edit]
```

Fields: name, short description, default duration(optional), default price(optional), active/inactive, associated coaches(optional). Session-level price/capacity may override defaults.

## Pricing note

Class definitions may contain a default customer-facing price for convenience.

The actual scheduled session may override that value.

Do not store coach compensation as public class information.
