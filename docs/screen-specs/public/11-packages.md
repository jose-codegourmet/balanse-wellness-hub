# Public — Packages

`/packages` lists published packages. `/packages/[slug]` shows sessions, price, eligible classes, validity, and that a package does not skip capacity, cutoff, or confirmation.

Draft and archived packages are omitted. Coach compensation never appears.

Guest browse is read-only. Claiming requires sign-in. Copy says **sessions**, never monetary “balance”.

Mock data: `getPublicBundles()` / `getPublicBundle(slug)`.
