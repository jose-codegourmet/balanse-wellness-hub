# 13 — Check-in, Attendance, and No-show

## Check-in owner

**CONFIRMED:** Coach Rex/admin performs the normal check-in.

The customer does not self-check-in for MVP.

## Customer proof of booking

The customer profile should show the booking and its status.

A confirmed booking should have a clear confirmation view that the customer can show to staff.

This is a booking confirmation, not necessarily an official tax receipt.

## Admin check-in flow

1. Customer arrives.
2. Staff/admin finds the customer in the class roster or booking.
3. Admin verifies the booking is valid/confirmed.
4. Admin marks the customer checked in.

## No-show

If a customer has a valid booking but fails to attend:

- admin can mark the booking `NO_SHOW`,
- no refund is issued.

## Attendance visibility

Admin should be able to see for each session:

- expected attendees,
- confirmed customers,
- checked-in customers,
- no-shows.

## Official receipt

The system is not required to issue an official receipt in MVP.

Any official/physical receipt process can remain part of the gym's existing operational process unless the client later requests a compliant digital receipt feature.
