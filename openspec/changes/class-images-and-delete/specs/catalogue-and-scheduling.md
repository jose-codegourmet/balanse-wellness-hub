# Delta: Catalogue and scheduling

Base: `openspec/specs/catalogue-and-scheduling.md` (requirements 1–10). Merge on archive.

## MODIFIED Requirements

3. Admin can create, edit, publish or retire catalogue entries from `/classes/**` and `/coaches/**`. Class copy, cover, gallery and teaching roster are managed separately from the scheduled session. **Class cover and gallery images are uploaded by staff with `classes.manage` through a signed upload intent and stored as public marketing URLs; the editor recommends 16:9 landscape but enforces no ratio. A Super Admin may hard-delete a class that has no sessions and no bundle applicability; any other class is deactivated instead.** A coach's internal default rate and rate type are available only on authorized admin surfaces.
