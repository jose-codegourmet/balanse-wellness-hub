# OpenSpec draft — FE foundation

## Why

Stand up the Balansé frontend monorepo so later screen tickets can land mocked UI without template demo leftovers or live backend calls.

## What

- Bootstrap from `fe-multi-web-template`, Balanse package scope
- Jabkit as the source-distributed component library
- Brand tokens, mock adapter, mock session harness
- Public, customer, and admin route shells
- Shared upload primitive, Storybook a11y gate, money/date helpers

## Out of scope

FE-SHR / FE-PUB / FE-CUS / FE-ADM screen content, WIRE-* auth/data, generated marketing assets.
